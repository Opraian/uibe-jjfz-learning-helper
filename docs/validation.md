# 验证说明

版本：1.1.0 开发测试版，未发布新版 Release。检查日期：2026-11-16。

测试集包含 71 项离线测试，使用人工构造的 HTML 和受控媒体状态，不使用任何账号页面、Cookie、令牌、真实视频或个人文件。

## 覆盖范围

- 课程、当前章节、目录、播放时间与页面已有完成标记的识别。
- 分节课程和独立课程链接去重；站外和其他课程链接排除。
- 常规继续、续播、首次说明和正常完成提示的分类及单次处理。
- 异常、登录过期、异地登录、验证码、未知提示和视频加载错误的暂停。
- 同时出现多个提示时异常优先；隐藏旧提示不干扰正常提示。
- 自然播放结束时等待平台确认；确认且提示关闭后才开放或尝试进入下一节。
- 连续播放、弹窗与续播开关；新标签页启用、停止和多个标签页的独立会话。
- 暂停后正常续播、浏览器禁止自动播放时的手动入口、结束后不自动重播和未就绪播放器等待。
- 综合列表识别章节、每章进入精品课程及必修、课程卡片直接进入辅助、必修分页和完成后转入下一章。
- 两章完整导航链的模拟：不确认则等待，确认后返回必修列表；两章都明确完成后才结束流程。
- 缺少课程入口、必修筛选、分页、返回列表或章节不一致时停止，不推测地址或完成状态。
- 重复注入保护、内容以纯文本显示、非目标域名不运行。
- 清单权限、品牌名和不修改平台进度 / 倍速 / 计时器的源码检查。

合成播放页面包含 4 节；合成课程列表包含 19 个章节或独立课程入口，4 个明确完成标记；合成综合列表含 3 章，其中 1 章明确完成。测试中，布局可见性和媒体状态由测试夹具提供。jsdom 记录导航尝试，不真正跳转或加载目标页。

## 尚待验证

以下项目需要真实 Chrome 与有效平台登录会话，当前未完成：

1. Chrome 安装和 Manifest V3 内容脚本加载。
2. 面板实际布局、遮挡、卡片快捷入口和综合课程列表的章节识别。
3. 网站真实事件处理程序对扩展点击的响应。
4. 章节选择、精品课程、必修、自动播放、自然结束、服务器成功确认、页面刷新和下一个视频 / 章节的完整在线流程。
5. 平台更新或额外弹窗文案的兼容性。

离线测试通过不代表服务器最终认可学习记录。验证应沿用正常播放流程，不主动制造异常或触发验证。
