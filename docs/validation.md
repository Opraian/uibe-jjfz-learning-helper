# 验证说明

版本：1.0.1。检查日期：2026-11-16。

公开测试集包含 38 项离线测试，使用人工构造的 HTML 和受控媒体状态，不使用任何账号页面、Cookie、令牌、真实视频或个人文件。

## 覆盖范围

- 课程、当前章节、目录、播放时间与页面已有完成标记的识别。
- 分节课程和独立课程链接去重；站外和其他课程链接排除。
- 常规继续、续播、首次说明和正常完成提示的分类及单次处理。
- 异常、登录过期、异地登录、验证码、未知提示和视频加载错误的暂停。
- 同时出现多个提示时异常优先；隐藏旧提示不干扰正常提示。
- 自然播放结束时等待平台确认；确认且提示关闭后才开放或尝试进入下一节。
- 连续播放开关、弹窗开关、新标签页启用、停止和多标签页互斥。
- 重复注入保护、内容以纯文本显示、非目标域名不运行。
- 清单权限、品牌名和不修改平台进度 / 倍速 / 计时器的源码检查。

合成播放页面包含 4 节；合成课程列表包含 19 个章节或独立课程入口，4 个明确完成标记。测试中，布局可见性和媒体状态由测试夹具提供。jsdom 记录导航尝试，不真正跳转或加载目标页。

## 尚待验证

以下项目需要真实 Chrome 与有效平台登录会话，当前未完成：

1. Chrome 安装和 Manifest V3 内容脚本加载。
2. 面板实际布局、遮挡和收起操作。
3. 网站真实事件处理程序对扩展点击的响应。
4. 自然播放结束、服务器成功确认、页面刷新和下一节的完整流程。
5. 平台更新或额外弹窗文案的兼容性。

离线测试通过不代表服务器最终认可学习记录。验证应沿用正常播放流程，不主动制造异常或触发验证。
