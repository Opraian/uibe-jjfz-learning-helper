# UIBE jjfz 学习助手

用于 `jjfz.uibe.edu.cn` 的 Chrome 扩展，提供课程目录、平台完成状态、播放进度和常规提示处理。

当前为 **1.1.0 公开测试版**。离线检查通过，真实平台在线流程仍待实测。

## 功能

- 自动识别当前课程与章节，显示当前页的目录和平台已有的完成标记。
- 显示视频播放进度和剩余时间，在视频自然结束时提醒。
- 开启辅助后，自动点击已识别的常规“继续学习”“继续观看”和正常结束提示。
- 视频正常暂停后自动尝试续播；浏览器要求用户手势时，显示“点击继续播放”按钮。
- 平台明确确认本节完成后，提供下一节快捷入口；可单独开启同课程连续播放。
- 综合课程列表与课程卡片提供辅助入口；可按章节进入“精品课程 → 必修 → 视频”，在平台确认后继续下一个视频或章节。
- 遇到异常学习、登录过期、验证码、未知弹窗或播放器错误时，保留提示、停止辅助并暂停视频。
- 多个标签页可同时独立运行辅助，各自保存启停和章节流程。

**当前验证状态：71 项离线测试通过；真实 Chrome 安装、综合课程列表布局和服务器完成确认流程尚待在线实测。**

本项目是社区工具，与平台无隶属关系。

## 安装

需要支持 Manifest V3 的 Chrome 102 或更新版本。

1. 从 [v1.1.0 发布页](https://github.com/Opraian/uibe-jjfz-learning-helper/releases/tag/v1.1.0) 下载 `uibe-jjfz-learning-helper-v1.1.0.zip`，解压到长期保留的文件夹；也可直接使用仓库中的 `extension/` 文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的文件夹**。
4. 刷新 UIBE jjfz 课程页或播放页，右下角会出现助手。

也可以下载或克隆本仓库，在第 3 步选择仓库中的 `extension/` 文件夹；安装扩展本身不需要 Node.js。

ZIP 用于解压后本地安装。本项目尚未发布到 Chrome 应用商店。安装后请保留原文件夹；更新时替换文件，在扩展管理页重新加载扩展并刷新课程页。

参考 [Chrome 官方本地安装步骤](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 使用

### 从综合课程列表开始

点击助手的“开始必修辅助”，按当前页识别到的未完成章节顺序进入：

`章节 → 精品课程 → 必修 → 未完成视频 → 平台确认 → 下一节 / 返回必修列表 → 下一章`

也可点击章节卡片旁的“辅助本章必修”，只处理该章。缺少明确入口或无法识别分页时，流程会停在当前页面并说明原因。

### 从视频课程列表开始

点击课程卡片的“进入并辅助”或助手目录中的视频标题，即可进入视频页并开启当前标签页的辅助。点击助手的“开始必修辅助”则处理本章的必修范围。

### 从视频页开始

点击“开启辅助”启用当前标签页的自动操作。暂停时会尝试正常调用播放器继续播放。若浏览器禁止自动播放，点击面板的“点击继续播放”即可；遇到异常或验证时保持停止。

| 选项 | 默认值 | 行为 |
| --- | --- | --- |
| 自动点击常规继续学习 / 结束提示 | 开启 | 在辅助运行时处理已识别提示 |
| 暂停后自动尝试继续播放 | 开启 | 正常暂停后尝试续播；浏览器限制时提供手动按钮 |
| 平台确认完成后自动进入下一节 | 关闭 | 开启后，在平台确认且提示关闭后进入同课程下一节 |

按章节处理必修课时，流程会连续进入该范围内后续视频，此时“自动进入下一节”显示为开启并由流程管理。

“停止辅助”停止自动点击和跳转，播放由网站控制。异常导致的停止需要先处理网站提示，再主动重新开启辅助。

辅助状态和流程位置在同一标签页刷新或正常翻页后保留，浏览器重启后需要重新开启。每个标签页独立启停，互不抢占。面板可通过右上角“−”收起。

目录中的“未标记完成”表示当前页面没有明确完成标记。视频自然结束后仍需平台确认；页面处于后台时保留网站原有暂停行为。

## 数据与权限

运行权限仅包含 `storage`，内容脚本限定到 `jjfz.uibe.edu.cn` 的 HTTP / HTTPS 页面。

- 本地保存弹窗开关、连续播放开关、自动续播开关和面板收起状态。
- 会话存储分别保存各标签页的启停状态、章节链接、必修列表入口和当前流程位置；当前页日志保留在内存中。
- 扩展没有外部服务、统计上报、远程脚本或云端同步，不读取账号密码、Cookie 或页面令牌。
- 扩展不改倍速、播放时间、可见性检测或网站计时器，不主动发送学习进度或完成请求。

## 开发与测试

需要 Node.js 22.13+；项目的 CI 使用 Node.js 24。

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run package
```

安装包输出到 `dist/`。运行依赖全部随源码提供，Node.js 依赖仅用于开发、测试和打包。

测试使用人工构造的最小 HTML 和模拟媒体状态，不加载网站脚本，不连接真实服务器，也不依赖开发者电脑上的文件。具体范围与限制见 [验证说明](docs/validation.md)。
